# Bundled Myanmar caption fonts

These fonts are bundled for local preview and FFmpeg subtitle rendering. They were selected from
the [Myanmar Unicode Fonts collection](https://github.com/AungMyoKyaw/Myanmar-Unicode-Fonts) after
checking the license metadata embedded in each font file.

| File | Editor name | License |
| --- | --- | --- |
| `NotoSansMyanmar-Regular.ttf` | Noto Sans Myanmar | Apache License 2.0 |
| `Padauk.ttf` | Padauk | SIL Open Font License 1.1; reserved font name “Padauk” |
| `Pyidaungsu.ttf` | Pyidaungsu | SIL Open Font License 1.1 |
| `TharLon.ttf` | TharLon | SIL Open Font License 1.1 |
| `MyanmarSansPro.ttf` | Myanmar Sans Pro | Apache License 2.0 |

The complete license texts are included as `LICENSE-APACHE-2.0.txt` and `LICENSE-OFL-1.1.txt`.
Microsoft Myanmar Text is intentionally not bundled because its embedded terms do not grant the
same redistribution rights.
